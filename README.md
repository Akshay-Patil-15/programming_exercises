# Leetcode

Daily Leetcode solutions. One notebook or file per problem, grouped by topic.

## Structure

Organize by topic, e.g. `arrays/`, `trees/`, `dynamic-programming/`. Name files with problem number and slug when possible: `001-two-sum.ipynb`.

## Daily workflow

```bash
# After solving a new problem
git add .
git commit -m "Add: <problem name or number>"
git push
```
